How does this work?
  1. Researchers measured how active each gene was in five kinds of worms: normal worms and four strains with changed genes.
  2. Those measurements go into a computer model of the worm's metabolism (the chemical reactions that keep it alive), which works out how fast the worm can grow.
  3. The slower the model says a worm can grow, the longer it is predicted to live. This is the "model estimate".
  4. The same researchers also measured how long each kind of worm lived. Those measured lifespans set the main survival curve.
What do the results mean?
  • Measured lifespan is how long this worm lived in the lab, compared with a normal worm. 2.00× means twice as long.
  • Model estimate is what this project's metabolic model predicts for the same worm. It is a simple model and can be far off.
  • Measured vs model shows how far the model is from the lab result.
  • Growth compared with a normal worm comes from the model: 1.0000 means the same as a normal worm, and lower means slower.

Measured numbers come from a published lab study. Model numbers come from a simple research model, shown with its error. Only the five worm types in the dataset are covered so far.
